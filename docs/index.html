📚 Available Endpoints

GET /health

Description: Health check endpoint to verify API is running

Response: Returns API status

Example:

curl https://tcss-460-group-7-tv-shows-dataset-api-g4kq.onrender.com/health

Response:

{
  "status": "healthy",
  "message": "API is running"
}

GET /api/shows

Description: Retrieve all TV shows from the database

Returns: Array of TV show objects

Example:

curl https://tcss-460-group-7-tv-shows-dataset-api-g4kq.onrender.com/api/shows

GET /api/shows/by-genre/{genre}

Description: Filter TV shows by genre

Path Parameter: genre - The genre to filter by (e.g., Drama, Comedy, Action)

Example:

curl https://tcss-460-group-7-tv-shows-dataset-api-g4kq.onrender.com/api/shows/by-genre/Drama

Common Genres: Drama, Comedy, Action, Sci-Fi, Horror, Thriller, Romance, Crime

⚠️ Error Responses

If something goes wrong, the API returns an error:

{
  "error": "Genre not found",
  "message": "No TV shows found for the specified genre"
}

Common Status Codes

  • 200 OK - Request successful
  • 404 Not Found - Resource not found
  • 500 Internal Server Error - Server error

💡 Usage Tips

  • Use the health endpoint to check if the API is up before making requests
  • Genre filtering is case-sensitive (use "Drama" not "drama")
  • The API returns all shows at once (no pagination in Beta Sprint)
  • Try the interactive documentation below to test endpoints live!
